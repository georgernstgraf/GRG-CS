# Conventions

Coding patterns, naming rules, and style agreements for this project.
Follow these without question. Do not deviate unless explicitly told.

## PDF-Lesung
- Skriptum immer mit `pdftotext skriptum.pdf -` lesen

## Hausübungen
- Neue Hausübungen in `3ahwii/Hausübungen.md` eintragen
- Aktuelle Themen aus `3ahwii/README.md` entnehmen
- Nicht zu schwer für Schüler; Bonusaufgaben für "sehr gut" kennzeichnen

## Git Commits
- Jede Commit-Message MUSS die korrespondierende Ticket-Nummer enthalten (z.B. ` #6 `)
- Ticket-Nummer muss von Leerzeichen umgeben sein

## Code-Konventionen (aus AGENTS.md)
- Ziel-Framework: .NET 8.0
- Testing: xUnit
- Namenskonventionen: PascalCase für Klassen/Methoden/Properties, _prefix für private Felder
- Nullable Reference Types: Enabled
- Sprache: Deutsch für Kommentare, Dokumentation, User-facing Text
